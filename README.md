# Personal Drive Sync

Personal Drive Sync is a private, personal-use setup for accessing and managing Google Drive files on my own computer using [rclone](https://rclone.org/).

## Purpose

This project is intended solely for my personal file management and backup workflows. It is not a commercial service and is not offered to other users.

## How it works

rclone runs locally on my computer and connects to Google Drive through the Google Drive API using OAuth 2.0 authorization. Google account access is granted by me through Google's authorization process.

I do not operate a server that provides access to other people's Google Drive accounts.

## Data handling

Google Drive access is used only for my personal file-management tasks. OAuth credentials and tokens are maintained as part of my local rclone configuration. Files are transferred between my computer and Google Drive as requested by my own commands and configuration.

This project is not affiliated with Google.
